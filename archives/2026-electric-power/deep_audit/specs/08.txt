        算子功能

        潮流分析中需要对实对称矩阵做谱分解，例如节点电压变化的协方差矩阵、加权拉普拉斯矩
        阵的谱分析等。这类矩阵的特征值均为实数，可以用对称特征分解 A = Q diag(λ) Qᵀ 描述
        其主方向与能量分布。

        本算子接收（一批）实对称方阵 A ，输出非降序排列的特征值与正交特征向量矩阵。

        计算规则：


           A_eff = tril(A) + tril(A, −1)ᵀ                    （UPLO = 'L'，由下三角补全）
           A_eff = triu(A) + triu(A, 1)ᵀ                     （UPLO = 'U'，由上三角补全）
           A_eff = Q diag(λ) Qᵀ                              Q 正交，λ 为实数
           λ₁ ≤ λ₂ ≤ … ≤ λ_n                                 （非降序）



         A 的对称性不做检查：未被 UPLO 选中的三角可以是任意值，分解与重构针对的是由选中
        三角补全得到的 A_eff 。

        输入输出规格

                   张量                    形状        数据类型                           含义

          A                          [\*, n, n]    float32     实对称矩阵（ * 为零个或多个 batch 维）

          eigenvalues                [\*, n]       float32     非降序特征值

          eigenvectors               [\*, n, n]    float32     特征向量矩阵，特征向量按列存放

        维度约束：n ∈ [1, 512]，batch 维大小 ∈ [1, 64]。输入数据保证 A_eff 的特征值互不相
        同（最小间隔 ≥ 1e-4·‖A_eff‖₂），以免特征向量在重根附近不连续。

        属性参数

             参数                类型                  默认值                      含义

          UPLO             'L' / 'U'          'L'        使用下三角（'L'）或上三角（'U'）参与计算


        功能示例

        取 A = [[2, 1], [1, 2]] ，特征值为 λ = [1, 3] ，特征向量矩阵（按列）为 Q = [[-1/
        √2, 1/√2], [1/√2, 1/√2]] （列整体变号等价）；把上三角换成任意大数， UPLO='L' 下结
        果不变，因为 A_eff 仍是 [[2, 1], [1, 2]] 。该示例用于确认三角选择与特征值排序正
        确。

        任务要求

        针对不同 shape 规模和 batch 配置，设计算子逻辑，保证算子精度正确：特征值逐元素满
        足 atol ≤ 1e-4、rtol ≤ 1e-4。特征向量存在列整体变号的自由度，故不以逐元素比较考
        核，改为校验正交性 ‖QᵀQ − I‖_F ≤ 1e-4 与重构误差 ‖A_eff − Q diag(λ) Qᵀ‖_F ≤ 1e-
        4·‖A_eff‖_F 。

        在保证正确性的前提下，充分发挥系统的计算能力和数据搬运能力，优化算子效率。

        禁止事项：禁止调用完整的对称特征分解实现、CPU回退、只输出部分特征对。
