        算子功能

        电力系统潮流计算中，牛顿–拉夫逊法的每一轮迭代都要先求解一个线性修正方程 A Δx =
        b （ A 为该轮迭代的雅可比矩阵），再用解出的修正量更新电压幅值与相角；在固定线性化
        矩阵下，多右端计算可共享同一个系数矩阵。

        本算子接收（一批）方阵 A 与右端项 B ，输出满足 AX = B 的解。

        计算规则：


           A X = B                                  A ∈ R^{n×n}, B ∈ R^{n×k}



         A 可逆时解唯一，即 X = A⁻¹B 。

        输入输出规格

           张量                       形状              数据类型                          含义

          A            [\*, n, n]                   float32     系数矩阵（ * 为零个或多个 batch 维）

          B            [\, n, k] / [\, n]           float32     右端项，矩阵形式或向量形式

          X            与广播后的 B 同形                   float32     线性方程组的解


        维度约束：n ∈ [1, 512]，k ∈ [1, 256]，batch 维大小 ∈ [1, 64]。按官方规则， A 形状为
         (*, n, n) ；当 B 形状为 (n,) 或 (n, k) 而 A 带 batch 维时， B 广播到 (*, n) 或
         (*, n, k) ，输出与广播后的 B 同形。输入数据保证 A 可逆、解唯一，且条件数有界
        （ cond₂(A) ≤ 1e3 ）。

        支持范围：固定 left=True （只求解 AX = B ）；不接受稀疏张量形式的 A 。

        属性参数

            参数             类型             默认值                               含义

          left           bool           True        求解 AX = B （True）或 XA = B （False）


        功能示例

        单位系数矩阵：取 A = I ，则输出 X = B ；对角系数矩阵：取 A = diag(d) （ d 为非零
        对角元），则输出按行缩放 X[i, :] = B[i, :] / d[i] 。该示例用于确认求解过程没有引
        入错误的缩放或置换。

        任务要求

        针对不同 shape 规模和 batch 配置，设计算子逻辑，保证算子精度正确：逐元素满足 atol
        ≤ 1e-4、rtol ≤ 1e-4，且残差满足 ‖AX − B‖_F ≤ 1e-4·‖B‖_F 。

        在保证正确性的前提下，充分发挥系统的计算能力和数据搬运能力，优化算子效率。

        禁止事项：禁止调用完整的线性方程组求解实现、CPU回退。
