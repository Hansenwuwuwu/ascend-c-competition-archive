        算子说明

        算子功能

        基于电网拓扑的潮流代理模型把潮流结果拟合为图上的学习任务：母线作为节点、支路作为
        边，节点与边的特征描述运行状态，用图卷积在拓扑上聚合信息。SplineConv 用伪坐标上
        的 B-spline 张量积基构造随该连续量变化的卷积核，可用于这类代理模型的信息聚合。

        算子接收节点特征、边表、边的伪坐标与核权重，先逐边计算 B-spline 基函数与权重索引，
        再按索引取得核权重完成加权，最后按目标节点聚合，并可选地叠加节点自身特征的线性变
        换与偏置。该边界对应 PyG 官方 SplineConv.forward 的语义。

        计算规则：


           S = (degree + 1)^dim,             K = ∏_d kernel_size[d]


           对每条边 e 与基函数槽 s（s = 0 … S−1）：
                 k = s;     wi = 0;      off = 1;        b = 1
                 for d = 0 … dim−1:
                      k_mod = k mod (degree+1);              k = k div (degree+1)
                      v_d      = pseudo[e,d] · (kernel_size[d] − degree · is_open_spline[d])
                      wi      += ((⌊v_d⌋ + k_mod) mod kernel_size[d]) · off;           off ← off · kernel_size[d]
                      b       ← b · B_degree(frac(v_d), k_mod)
                 basis[e,s] = b;           weight_index[e,s] = wi


           message[e,:] = Σ_s basis[e,s] · (x[src[e],:] @ weight[weight_index[e,s],:,:])

           out[i,:]           = Σ_{e: dst[e]=i} message[e,:] / (deg(i) 若 aggr='mean'，否则 1)
           out                = out + x @ root_weight + bias

        属性参数

                     参数                         类型            默认值                        含义

          dim                             int            必选                  伪坐标维度

          kernel_size                     list[int]      必选                  每一维的核尺寸，长度 = dim

          is_open_spline                  list[bool]     [True] × dim        每一维使用开/闭 B-spline 基

          degree                          int            1                   B-spline 基阶数，取 1/2/3

          aggr                            str            'mean'              聚合方式，'add' 或 'mean'


         is_open_spline 只影响式中的缩放因子（开样条取 kernel_size[d] − degree ，闭样条
        取 kernel_size[d] ）； degree 决定每维基函数个数与 S ，须与分片多项式表一致。

        功能示例

        常数核退化：取 weight[k] 对所有 k ∈ [0, K) 为同一个矩阵 W₀ ，并取 root_weight
        = 0 、 bias = 0 。 由 单 位 分 解 有                              message[e,:] = x[src[e],:] @ W₀ ， 于 是
         aggr='mean' 时输出为邻域均值传播 x'_i = mean_{j∈N(i)} (x_j W₀) ， aggr='add'
        时输出为 Σ_{j∈N(i)} x_j W₀ 。该示例用于确认基函数求和归一、gather 索引与聚合方向
        正确。
